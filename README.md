# jpydzr9-fantastyczna-czworka

Webowa aplikacja do zarządzania budżetem domowym, umożliwiająca kontrolę finansów w jednym miejscu.  
Użytkownik może tworzyć konta bankowe oraz przypisane do nich oszczędności, cele finansowe i wydatki podzielone na kategorie.

Projekt został zrealizowany jako projekt zespołowy w celu nauki pracy z frameworkiem Django
 oraz współpracy zespołowej z użyciem Git.


Funkcjonalności: 
- Tworzenie i zarządzanie kontami bankowymi
- Rejestrowanie wydatków
- Kategoryzowanie wydatków (np. jedzenie, rachunki, rozrywka)
- Definiowanie celów finansowych
- Zarządzanie oszczędnościami przypisanymi do kont
- Podgląd struktury wydatków i oszczędności
- Przypisywanie danych do konkretnych kont bankowych

Backend
- Python
- Django
- Django ORM

Frontend
- HTML
- CSS

Baza danych
- SQLite
